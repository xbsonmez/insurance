## Kullanılan Teknolojiler

- **Next.js 15** (App Router)
- **React 19**
- **TypeScript 5** (`strict`)
- **Tailwind CSS 3**
- **lucide-react** (ikonlar)

## Kurulum & Çalıştırma

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production derleme
```

Geliştirme Node 26 ile yapıldı.
